# Release gates

| Gate | Exit criteria | Evidence |
| --- | --- | --- |
| **P0** Engineering truth + privacy/safety foundations | Reproducible build/tests; gap matrix current; unsafe nutrition presets flagged; personal data inventory; coaching service boundary defined; legal/regulatory review tasks tracked (not claimed done) | CI green; `MASTER_TODO` P0 VERIFIED; counsel engagement recorded |
| **P1** Coaching intelligence | MemberState + evidence registry + constrained recommendations + Yazan tools; member confirmation; no free-form plan invent | Unit/integration tests for S-* cases; tool schemas reviewed |
| **P2** Human coaching ops | Coach completes full weekly loop without DB access; access control + audit | Pilot coach walkthrough recording / checklist |
| **P3** Commercial + mobile | Paid member receives advertised tier via store-verified entitlements | Store sandbox transaction + entitlement check |
| **P4** Controlled pilot | Consenting adults; supervisors; turnaround/cost/safety metrics documented | Pilot report |

**Never** skip regulatory/security review to accelerate App Store submission.

Statuses for tasks: `BACKLOG → READY → IN_PROGRESS → REVIEW → VERIFIED → DONE` (+ `BLOCKED` with reason).  
**DONE** requires objective verification — not “file exists.”
