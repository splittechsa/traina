# ADR 0009 — Residency is unverified

## Status

Accepted as a constraint.

## Decision

This workspace does not claim compliance with the Saudi Personal Data Protection Law, a government cloud program, or any certification. Cross-border transfer is not approved.

Production hosting is blocked until an operator chooses a region and a processor list in writing.

## Consequences

Documentation may name candidate regions. It must not say the data already resides in the Kingdom.
