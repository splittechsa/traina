# Traina product spine

**The product is Yazan** — an AI coach that behaves like a real science-based online coach.

Everything else (water, food diary, workouts, supplements, macros, meal picks) is **daily input infrastructure** so Yazan can follow the athlete.

| Layer | Role |
| --- | --- |
| Logging (free) | Facts the coach reads |
| Yazan daily check-in | Coach speaks first from today’s + 14-day logs |
| Yazan chat | Conversation; proposals need confirm |
| Adaptive nutrition/training | Science-based plans per athlete goals + pace + adherence |
| Weekly survey | Athlete answers + auto packet → human coach file |

Human coaches receive weekly files; they do not replace the daily AI coach experience.
