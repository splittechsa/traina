## ما تم تنفيذه

لوحة RTL بإحصاءات تشغيلية فعلية واتجاه التمارين خلال 14 يومًا، بحث الأعضاء مع الصلاحيات، قائمة المدربين وربطهم وإلغاء الربط مع سبب، طابور المراجعات، طلبات اهتمام الموقع، تحديث حالات الدعم، وسجل العمليات. التحديثات تراعي الحالة السابقة وتُرفض عند التعارض؛ صلاحية admin تُقرأ من قاعدة البيانات في كل طلب، ويُرفض العضو العادي.

المتصفح يتصل ببوابة same-origin ذات قائمة مسارات وطرق مسموحة. رموز الدخول والتجديد محفوظة في كوكيز Secure وHttpOnly وSameSite=Strict؛ لا تُعاد ضمن JSON ولا تُخزّن في localStorage. التعديلات تتحقق من Origin، والبيانات غير الموثوقة تُهرّب قبل عرضها. لا تحتاج البوابة إلى أسرار قاعدة البيانات.

اللاندينق عربية وإنجليزية بتخطيط متجاوب وصور وهوية ترينا الحالية وخط محلي مرخّص. النموذج يتطلب موافقة صريحة ويكتب الاسم والبريد والاهتمام واللغة إلى الباك إند؛ الطلب يظهر في لوحة الإدارة. الفشل يحتفظ ببيانات النموذج ويتيح إعادة المحاولة. صفحات الخصوصية والشروط ما زالت مسودات غير معتمدة للإنتاج.

طبّقنا الترحيل 0034_website_interests.sql على مشروع Neon المعزول solitary-pond-59179148 فقط؛ إجمالي الترحيلات 34. مُنحت صلاحيات الجدول الجديد لدور التشغيل المحدود؛ لم تُنسخ بيانات عملاء إنتاجية ولم تُفعّل مدفوعات.

## الآيفون والتمارين

تم تحديث الأسطح والألوان والخطوط ومسافات العناوين العربية وشريط التبويبات، وتخفيف بطاقة يزن في الرئيسية والتدريب، وإتاحة إغلاق لوحة المفاتيح بالسحب. أصلحنا استيراد التنقل غير المتوافق مع Expo Router SDK57.

حفظ المجموعة يحرّر الإدخال بعد تأكيد SQLite المحلي ويجري مزامنة الشبكة بالخلفية. قفل فوري يمنع الضغط المزدوج، وحالات البدء/الإيقاف/الاستئناف/الإكمال تُظهر الانشغال وتلتقط الفشل. لا يُسمح بإنهاء الجلسة قبل تأكيد المجموعات المعلّقة. تجديد الدخول له مهلة 12 ثانية، ولا يمحو هوية الحساب عند عطل مؤقت في الخدمة. تدعم حقول الوزن والتكرارات الأرقام العربية والفارسية والفاصل العشري.

العرض ثلاثي الأبعاد لا يفتح GL تلقائيًا؛ يبدأ بطلب المستخدم، ويتوقف عند مغادرة الشاشة والخلفية وتقليل الحركة، مع تحرير موارد المعدات عند استبدالها. لم نقس FPS أو استهلاك الذاكرة على آيفون فعلي، ولا ندّعي انعدام التعليق على كل جهاز.

## الأدلة وحدودها

- 336 اختبارًا في الحزم: 136 domain + 3 contracts + 1 design tokens + 72 API + 124 mobile. خمسة اختبارات إضافية لبوابة الإدارة: الإجمالي 341.
- البناء وفحص الأنواع والـ lint ناجحة؛ توجد خمسة تحذيرات lint سابقة. نتائج المحاولات الأولية الفاشلة محفوظة، وتوثّق النتائج النهائية التصحيحات.
- اختبارات واجهة التمرين تثبت تحت طلب شبكة معلّق: رفض الضغط المزدوج، حفظ المجموعة محليًا مرة واحدة، وقبول المجموعة التالية دون انتظار الشبكة. واختبار منفصل يثبت تسجيل ١٢ تكرارًا و٧٢٫٥ كغ بالقيم الصحيحة.
- public-web-smoke.json: تسجيل الإدارة والكوكيز ورفض Origin غير المسموح وحفظ طلب الموقع وظهوره وتعارض التعديل والتدقيق وإلغاء الجلسة.
- public-api-smoke.json: 56 طلب HTTPS للمصادقة والملكية والتمارين ودورة البرنامج والمدرب البشري وGemini. نتائج AI تبقى REVIEW لحين اعتماد مهني مؤهّل.
- تصدير iOS نجح: 1999 module، Hermes bundle بحجم 6.1MB. وباندل التطوير من Metro الفعلي عاد 200؛ الدليل ios-development-bundle.json. هذا يثبت البناء والتوصيل، وليس تشغيلًا بصريًا على جهاز.
- واجهة المتصفح الآلي تعذّر تهيئتها بخطأ kernel assets؛ لذلك لا توجد لقطات شاشة أو مراجعة بصرية مكتملة للمتصفح أو الآيفون في هذا التسليم.

## الدخول والتشغيل

حساب إدارة اختبار اصطناعي: admin.preview.312b41dc@traina.test. كلمة المرور عشوائية محفوظة مشفّرة بـWindows DPAPI خارج Git. ملف Copy-AdminPassword.ps1 في حزمة outputs ينسخها إلى الحافظة عند تشغيله بحساب Ahmed على هذا الكمبيوتر، ولا يطبع كلمة المرور. لا تستخدمه لحسابات الإنتاج.

لرؤية تعديلات الآيفون، اضغط r في طرفية Expo الحالية. عند بقاء كاش قديم، أوقف Metro ثم نفّذ من apps/mobile:

```powershell
$env:EXPO_PUBLIC_API_URL='https://traina-staging-api.vercel.app'
$env:EXPO_NO_DOTENV='1'
node .\node_modules\expo\bin\cli start --go --lan --clear
```

تحقق فعليًا على الآيفون من العربية/الإنجليزية، الكتابة والكيبورد، التبويبات، بدء/إيقاف/استئناف/إنهاء تمرين، الحفظ دون إنترنت ثم المزامنة، والخروج للخلفية والعودة. اختبر تقليل الحركة وتشغيل/إيقاف نموذج التمرين. هذه الخطوات تبقى جهازية ولم تُستبدل باختبارات الكود.

## إعادة البناء والنشر

- الموقع: node scripts/build-public-site.mjs من جذر المستودع، ثم نشر apps/www كمشروعه المنفصل.
- الإدارة: نشر apps/admin-web مباشرة كمشروع static + Node Function، بدون إطار أو تثبيت اعتماديات واجهة جديدة.
- الباك إند: npm run build، ثم scripts/prepare-staging-source.mjs api <dedicated-directory>، وتحقق من source-manifest.json قبل النشر.
- متغيرات بوابة الإدارة: TRAINA_API_ORIGIN وADMIN_ORIGIN؛ ومتغيرات الموقع TRAINA_API_ORIGIN وWEBSITE_ORIGIN. الافتراضات الحالية هي عناوين staging المتحقَّق منها، ويجب تغييرها صراحةً لبيئة أخرى.
- الترحيلات تنفّذ بأداة المشغّل واتصال owner منفصل بعد التحقق من هوية قاعدة staging؛ لا تضف اتصال owner إلى الواجهات أو Vercel runtime.
- الاختبارات: npm test؛ npm run typecheck؛ npm test --prefix apps/mobile؛ npm run lint --prefix apps/mobile؛ node --test apps/admin-web/gateway.test.mjs.

بقيت المراجعة المستقلة واختبار الآيفون الفعلي والاعتمادات العلمية والتشغيلية والقانونية ومحقّق مدفوعات المتاجر مطلوبة. GitHub التلقائي لم يُربط بمشروع الإدارة بسبب صلاحية ربط المستودع في Vercel؛ النشر الحالي عبر CLI ناجح. لا توجد عملية دمج إلى master.
